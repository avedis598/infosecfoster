## Overview

This module sets up the single source of truth for the entire AML-SIEM platform code, configuration, and templates. Every file the platform uses — Kubernetes manifests, Helm values, client deployment scripts, Wazuh rules, Grafana dashboards, Shuffle playbooks — lives inside `/opt/aml-siem/`. Once this structure exists and is under Git version control, every engineer knows exactly where to put new files and where to find existing ones.

### Why this matters

Without a defined folder structure:
- Engineers guess where to put new files → files get scattered across `/tmp`, `/root`, `/home/user/` inconsistently
- Client deployments become impossible to reproduce
- Handoffs to new team members take days instead of hours
- Security audits become impossible — nobody knows what's actually deployed

With this structure:
- A new engineer clones the repo and sees the entire platform on day one
- The `deploy-client.sh` script in Sprint 6 walks this tree deterministically
- Every commit is a signed-off checkpoint that can be rolled back
- Secrets are enforced-out via `.gitignore` so no credential ever ends up in Git

Estimated time: **20–30 minutes**.

## Step 2 — Create the Root Folder with Correct Ownership

```bash
sudo mkdir -p /opt/aml-siem
sudo chown -R $USER:$USER /opt/aml-siem
cd /opt/aml-siem
```

**Why sudo + chown together:** `/opt/` is owned by root, so the initial `mkdir` needs sudo. Immediately handing ownership back to your user means every subsequent `git`, `vim`, and `mkdir` inside `/opt/aml-siem` works without sudo — cleaner and safer.

Verify:

```bash
ls -ld /opt/aml-siem
# Expected: drwxr-xr-x 2 amlsiem amlsiem 4096 ... /opt/aml-siem
```

## Step 7 — Add `.gitkeep` Files to Empty Folders

```bash

  -not -path './.git*' \
```

## Common Issues and Fixes

| Problem | Cause | Fix |
|---|---|---|
| Permission denied on `/opt/aml-siem` | Not using sudo | `sudo mkdir` then `sudo chown` |
| Empty folders not in Git | Git doesn't track empty dirs | Add `.gitkeep` files |
| `.env` accidentally committed | Created before `.gitignore` | `git rm --cached .env` |
| `git push` permission denied | GitHub doesn't know VM SSH key | Add pubkey to GitHub Settings |
